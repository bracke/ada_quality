# CLI reference

Commands are `project add/list/show/enable/disable/remove`, `check --all|--project ID [--json]`, `status`, `findings`, `regressions`, `history`, `report --format json`, `policy validate/show`, and `database init/check/recover`. Global options are `--database`, `--policy`, `--color`, and `--no-color`. Unknown options, missing values, and conflicting selectors are rejected.
