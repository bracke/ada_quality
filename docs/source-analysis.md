# Source analysis

Ada comments and strings are lexically removed where rules require code tokens. Complexity counts exact decision tokens and short-circuit operators per subprogram, not substrings. Library unit names are compared canonically with source filenames. Broad handlers use `project_tools` Ada source scanning; an audited cleanup, translation, or process-boundary handler may carry the explicit `AQ: audited exception boundary` suppression on its handler line. Cohesive orchestration and test-registry units that cannot be split without obscuring their contract may use the file-level `AQ: complexity-reviewed` or `AQ: size-reviewed` annotations after explicit review. Public spec documentation requires a nonempty standalone package comment.
