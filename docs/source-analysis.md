# Source analysis

Ada comments and strings are lexically removed where rules require code tokens. SRC-03 is a defined lexical Ada decision-complexity metric, not an AST claim: each subprogram starts at one; `if` (excluding `end if` and `elsif`), `elsif`, `when`, non-terminating `case` and `loop` tokens, `and then`, and `or else` each add one. The maximum segment between subprogram declarations is reported. Representative conditionals, alternatives, loops, short-circuit expressions, nested declarations, and expression functions are fixture-tested. Library unit names are compared canonically with source filenames. Broad handlers use `project_tools` Ada source scanning; an audited cleanup, translation, or process-boundary handler may carry the explicit `AQ: audited exception boundary` suppression on its handler line. Cohesive orchestration and test-registry units that cannot be split without obscuring their contract may use the file-level `AQ: complexity-reviewed` or `AQ: size-reviewed` annotations after explicit review. DOC-01 uses GNATdoc's declaration-level warning audit rather than accepting one file-level package comment as evidence for every declaration.
