# Regression detection

Regression kinds are new violation, worsened metric, increased severity, failed gate, lost evidence, and policy-induced change. Gate membership and numeric direction come from the immutable indicator registry: TST-02 registration counts and TST-03 coverage worsen when they fall; source-violation, complexity, security, and artifact counts worsen when they rise; indicators without a defined numeric direction are not trended. DOC-01 retains GNATdoc's diagnostic count as evidence but does not trend it because repeated GNATdoc runs can emit different cardinalities for identical source; pass-to-violation and stable finding comparisons still detect documentation regressions. Metric deterioration is reported even when both assessments remain in violation. A pass-to-violation on build/test/release/proof gates is a failed gate. Toolchain-incompatible, toolchain-unavailable, or incomplete runs are not compared and are reported as unavailable rather than clean.
