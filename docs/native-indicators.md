# Native indicators

STR indicators structurally validate the complete manifest before reading required top-level fields, then check
GPR/layout/tests/checker presence. SRC indicators measure formatting, naming, defined Ada decision complexity, hygiene,
handlers, and size. DOC-01 audits every public declaration through GNATdoc and DOC-03 checks required files. DEP-02
detects local pins. SEC indicators scan credentials, lexically recognized shell-oriented calls, links, and artifacts.
REL-02 parses the Alire SPDX declaration and verifies it against repository license contents. REL-03 validates the
canonical Alire release-manifest contract rather than a separate `manifest.json` artifact.
