# Native indicators

STR indicators validate manifest, GPR/layout/tests/checker presence. SRC indicators measure formatting, naming, defined Ada decision complexity, hygiene, handlers, and size. DOC-01 audits every public declaration through GNATdoc and DOC-03 checks required files. DEP-02 detects local pins. SEC indicators scan credentials, unsafe shell-oriented calls, links, and artifacts. REL-02/03 validate license and release manifest fields.
