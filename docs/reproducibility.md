# Reproducibility

Stable project IDs are processed in sorted order and one at a time. Source inventories and database queries are sorted. Policy and toolchain fingerprints define comparison compatibility. Tool output is bounded and digested. TST-04 requires two successful executions with equal normalized output and equal source-artifact fingerprints. Lines explicitly carrying elapsed-time, duration, timestamp, or `time:` presentation fields are omitted from the output comparison; test names, assertions, totals, errors, and all other output remain exact. Generated build directories are excluded from the artifact fingerprint, while project files created or changed by a test remain visible. JSON member order is deterministic.
